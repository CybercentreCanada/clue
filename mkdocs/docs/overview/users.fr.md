# Clue du point de vue de l'utilisateur

Les utilisateurs rencontreront généralement Clue via d'autres applications l'intégrant dans leur interface utilisateur,
bien qu'il puisse également être utilisé seul si nécessaire. Voici les différentes façons d'utiliser Clue :

## Données enrichies

L'une des façons dont Clue peut être utilisé dans d'autres applications est d'enrichir les données existantes, en
remplaçant un composant simple tel qu'une Chip ou Typography par une version enrichie. Ces données enrichies peuvent
afficher des icônes pour représenter soit une Évaluation (comme une IP évaluée comme "faux-positif"), une Opinion
(comme un nom d'hôte désigné comme "suspect") ou un Contexte supplémentaire (comme un drapeau de pays pour une IP géolocalisée).

Ces données enrichies peuvent également être interactives en cliquant dessus, ce qui affichera une fenêtre contextuelle
de détails. Dans cette fenêtre, vous pouvez trouver les informations que chaque plugin a fournies concernant les
données pertinentes. Dans ce menu, vous disposez de filtres rapides vous permettant d'affiner les enrichissements à
afficher, de liens externes vers les différents fournisseurs de plugins, ainsi que de boutons d'icônes pour
différentes actions qui peuvent être effectuées, telles que l'actualisation de la requête, la copie dans le
presse-papiers, l'exécution d'enrichissement supplémentaire ou l'exécution d'actions.

## Exécution d'actions

Clue permet également aux utilisateurs d'exécuter certaines actions spécifiques aux plugins. Ces actions seront
affichées sous le bouton "Exécuter" dans la fenêtre contextuelle de Clue, et peuvent être sélectionnées pour, par
exemple, pivoter vers une autre application ou soumettre les données à une autre application. Certaines actions
nécessiteront des informations supplémentaires et pourraient donc afficher un formulaire demandant les informations
manquantes.
